# Contributing

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

## Opening an issue

- Search the existing issues first to avoid duplicates.
- Open a new issue with a clear title, the steps to reproduce (for bugs), and the expected and actual behavior.

## Opening a pull request

1. Fork this repository and create a branch from `main`.
2. Make your changes and test them (for example, `bash -n simple-interest.sh` and a sample run).
3. Commit with a clear message and push the branch to your fork.
4. Open a pull request against `main` describing what you changed and why.
